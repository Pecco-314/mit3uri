# 三理 Mit3uri · 录播

三理 Mit3uri 的非官方粉丝录播索引，方便按日期查找直播回放与相关资料。

**[访问网站](https://pecco-314.github.io/mit3uri/)**

- 按年月浏览，支持标题、日期和 BV 号搜索。
- 汇集官方与民间录播链接。
- 逐步补充文字稿、摘要和标签。

## 开发

需要 Node.js 18+ 和 Python 3.9+，无需安装依赖。

```sh
npm run dev    # 本地预览
npm test       # 检查
npm run build  # 构建
```

推送到 `main` 后自动部署至 GitHub Pages。
